# Portfólio · Haian Vilas Boas

Site publicado em **https://dev-haian.github.io/**: Product Owner e QA Pleno em produtos financeiros.

- `index.html`: página inicial, com as duas trilhas de cases (Produto e Qualidade)
- `cases/`: uma página por case, geradas por `build_cases.py`
- `assets/`: estilo e currículos em PDF

Para editar um case, altere o texto em `build_cases.py` e rode `python3 build_cases.py`.
